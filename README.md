# Sociis Group

Website for Sociis Group, deployed at [the300.sociisgroup.com](https://the300.sociisgroup.com).

## Development

Install dependencies with `bun install`, then run `bun run dev` to start the local development server.

## Deployment

The project is connected to Lovable and Vercel. Commits pushed to the connected branch sync to Lovable and trigger the configured deployment.
